# Judgement

How the calls are made. These rules decide what counts; `definitions.md`
says what the words mean. Apply the same test to every voice, the host
included.

## Judge threads by outcome, moves by conduct

Keep two ledgers.

- **Thread ledger (outcome).** Where did each thread end? A dodge that
  happened to start a useful thread does not make the thread's outcome
  worse; judge the thread by where it ended.
- **Conduct ledger (moves).** Every distraction is logged against the person
  who made it, even if things turned out fine. Lucky is not the same as good.

## Dodges

- Only flag a reply to a real bid (see `definitions.md`). If the point was a
  passing remark, the silence is not a dodge.
- Give the reply a fair window. An answer can come one or two turns later, or
  after the moderator steps in. It is a dodge only if it never comes and the
  thread loses its way.
- "We don't know" is an answer. So is "I disagree, because ...". A reply that
  engages with the bid and rejects it is engagement, not a dodge.
- When nobody replies at all, it is an unanswered bid, not a dodge: its time
  is `talk`, and it goes in the `unanswered` list against its owner
  (`definitions.md`). It can also be a missed opportunity.

## Unanswered bids: signals, not noise

- Only weighty bids aimed at the other side. If you would hesitate to defend
  the entry to the person it names, leave it out.
- Give the reply the same fair window as a dodge: an answer one or two turns
  later, or after the moderator steps in, counts.
- Mark `matters` only when the bid could have led to a step within reach
  (`definitions.md`, Missed opportunity). The page leads with these.
- Expect a handful per conversation, not dozens. A long list means the bar
  for "weighty" is too low.

## Answers that left a gap: structure, not persuasion

- Name the gap in one line using the asker's own question: "Asked for a date;
  gave a reason, not a date." If you can't name it without your own view of
  the topic, it is a disagreement, not a gap. Leave it out.
- Judge only scope (was all of it answered?), support (was any reason given?)
  and link (does the reason bear on the question?). Never judge whether the
  reason is good; that is for the other side to argue.
- Give the same fair window: if the gap is filled one or two turns later, or
  after a follow-up, it is not a gap.
- Write the follow-up that would have closed it, in one line, as the asker or
  moderator could have said it.
- An unchallenged gap is not progress: its time is `talk`, and a thread that
  ends on one cannot be `converged`.
- Mark `matters` only when closing the gap was a step within reach. Expect a
  handful, like unanswered bids.
- Swap test: would you flag the same answer from the other side?

## Unprompted distractions

- Judge by effect on the thread, not by tone. A sharp, rude, on-point reply is
  not a distraction; a polite change of subject is.
- An unsourced number is not by itself a distraction. It becomes one when it
  is used in place of an argument, or when it takes over the thread.
- Never guess at motive. Report the move and what it did to the thread.

## Missed opportunities

- Find them at each distraction and at each bid nobody took up. Ask one
  question: "With only what was said up to this moment, what progress was one
  or two moves away?"
- Build the missed step only from things already in the transcript, with a
  time for each. If you need outside facts or a cleverer argument, it was not
  within reach; drop it.
- Prefer small, concrete steps: a shared list of questions, a test both sides
  accept, a defined word, a narrowed question, a condition, a next action.
- 2 to 4 missed steps for the whole conversation. Each names its thread and
  the moment it was lost.

## Consequences

- For a missed step, write 2 or 3 lines that follow from the miss, each one a
  step worse than the last ("So ... So ..."). Harm compounds; the last line is
  the one people should remember.
- For a reached step, write 1 or 2 lines on what it makes possible.
- Stay accurate. "More distrust in elections", not "people stop trusting
  elections". If two misses lead to the same end, write that end once as the
  shared outcome.

## Replay

- One replay per thread that ended `stuck` or `dropped`; optional for others.
- Same voices, same views, same facts as the real conversation up to the
  moment the thread went wrong. Start the replay there, not from the
  beginning.
- 3 to 6 short lines, by role. Each line is something that voice could
  plausibly have said, given what it had already said.
- End with the state the replay reaches, using the states in
  `definitions.md`. If a fair replay still ends `stuck`, say so; that is a
  finding too.

## Time

- Cover the whole run time with segments; no gaps, no overlaps.
- A distraction segment carries its label and the thread it pulled away from.
  If it pulled away from no thread in particular, leave the thread empty.
- `fwd` only for stretches where a good move actually happened. On-topic talk
  that nobody engaged with, or an answer that left a gap, is `talk`, however
  good it sounded.

## Voices

- One green dot per good move, one orange dot per unanswered bid the voice
  owns, one hollow orange dot per answer of theirs that left a gap, one red dot per distraction or omission, each with a time. Never a
  numeric score or grade for a person.
- For each red dot, write the **better move** (same view, better conduct) and
  its **cost** to the conversation.
- Moderator omissions count: letting a detour run, not following up on a bid
  nobody took up, closing without saying what was settled.

## Provenance

Every judgement on the page must trace back to a timestamped moment, or say
plainly that it is about something nobody said ("Nobody said what would make
them drop the demand"). If you can't point to the moment, cut the judgement.
